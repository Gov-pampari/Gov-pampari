## 👨‍💻 About Me

I'm a software engineer and product-focused builder interested in designing **scalable software systems, AI-powered products, and intelligent developer experiences**.

My engineering approach combines strong fundamentals in software development with practical experience across **AI/ML, full-stack development, databases, cloud infrastructure, and product engineering**. I enjoy taking an idea from **problem discovery → architecture → implementation → deployment → iteration**, with a strong focus on reliability, maintainability, performance, and real-world impact.

```text
Engineering Philosophy
────────────────────────────────────────────────────────────
Build simple systems.
Design for scale.
Automate repetitive work.
Measure what matters.
Ship products people actually use.
```
